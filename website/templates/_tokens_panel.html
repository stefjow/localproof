{# Proximity tokens: the owner's list (Wi-Fi, revoke) and the add flow (install firmware, read the key over WebSerial, register). A token's Wi-Fi networks go to it over WebSerial, never to the server. Rendered client-side from /api/my-tokens; loadTokens() is called by the drawer opener. #}

A token is a small ESP32 you carry. Next to a station it answers timed radio challenges, and your validations there count as proximity-verified. With Wi-Fi set up it uploads the proof itself, so you don't need to scan.

Add a token
Setting up a token needs a USB connection to the board, which only Chrome or Edge on a desktop can open.
Install requires Chrome or Edge on desktop. Open this page over HTTPS to install.
Erasing the board gives the token a new key and forgets its Wi-Fi, so a reinstalled token has to be registered again. If the install fails, hold BOOT while clicking Install. Once registered, set up its Wi-Fi from its card above.
