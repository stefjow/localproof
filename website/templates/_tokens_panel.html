A token is a small ESP32 you carry. Next to a station it answers timed radio challenges, and your validations there count as proximity-verified.

You haven't registered any tokens yet.
Add a token
Setting up a token needs a USB connection to the board, which only Chrome or Edge on a desktop can open.
Install requires Chrome or Edge on desktop. Open this page over HTTPS to install.
Erasing the board gives the token a new key, so a reinstalled token has to be registered again. If the install fails, hold BOOT while clicking Install.
